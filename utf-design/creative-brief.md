# Creative Brief

## Project

Redesign the existing public website of **Until They Fall**, a melodic death metal band from Brussels.

This document concerns the **simple / functional site experience**, not the future fully immersive lore experience.

The simple site still needs a strong artistic identity.

## Problem with the current site

The current site is functionally solid but visually too close to a SaaS/product website.

Recurring problems include:

- boxed content
- rounded cards
- repeated grids
- pills and badges
- generic functional icons
- repeated `eyebrow + title + paragraph + CTA`
- sections with similar visual weight
- UI elements being more visible than the band's imagery
- explanatory copy where visual confidence would work better

The result is readable, but it does not feel enough like a band with a distinct world.

## Desired outcome

The redesign should feel:

- dark
- cinematic
- editorial
- industrial
- ritualistic
- brutal but controlled
- atmospheric
- photographic
- recognisable as Until They Fall

It should **not** feel like:

- a SaaS landing page
- a startup website
- a generic metal WordPress theme
- a gaming UI
- a cyberpunk dashboard
- "AI art pasted onto a website"

## Brand universe

The site's visual system may draw from the following established concepts:

### Gerard

Gerard is a recurring entity/mascot associated with four eyes.

The four-eye symbol is a strong candidate for a recurring visual motif.

### Tower Seven

Tower Seven is a colossal AI complex.

Useful visual themes:

- monumental industrial architecture
- brutalism
- machinery
- heat
- surveillance
- concrete
- cables
- technical documentation
- warning systems
- infrastructure presented almost like religion

### The Book of GG

The lore frames artificial intelligence, human dependency, surveillance and the Seven Deadly Sins through Gerard and the Towers.

The site should not explain the entire lore on the public homepage.

Instead, the simple site can borrow its visual language.

### Seven Deadly Sins

The Seven Sins can become a long-term design system for releases.

Each chapter/song may later receive:

- its own accent colour
- symbol
- image treatment
- typography variation
- environmental motif

The shared base identity should remain consistent.

## Audience

The public site must work for:

- existing fans
- new listeners
- concert visitors
- promoters and venues
- bookers
- press
- people looking for merch
- people who simply want links quickly

## UX principle

The user must never be forced to engage with the lore.

The site should communicate:

> This band has a world.

without requiring:

> You must understand the world before you can find Spotify.

## Relationship with the immersive experience

Simple site:

- immediate
- readable
- fast
- music-first
- visual
- practical

Immersive world:

- narrative
- experimental
- interactive
- slower
- atmospheric
- lore-heavy

Both experiences must share:

- typography
- symbols
- image treatment
- visual language
- core colours
- Gerard / four-eye motifs
