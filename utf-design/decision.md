# Locked Design Decisions

## Current era
Until They Fall is currently presented through the Sent To Die era.

Do not display:
- chapter numbering
- "Chapter VI"
- Wrath as the current release
unless explicitly updated later.

## Genre wording
Use consistently:
"Melodic death metal from Brussels"

Do not alternate with:
"Modern metal from Brussels"

## Current visual accent
Base:
- near black
- dirty white
- neutral grey

Accent candidate:
- burnt red / dark ember

Do not introduce multiple accent colours on the same page.

## Typography
Test only these 2 directions:
1. Condensed display + neutral grotesk + mono metadata
2. Heavy grotesk display + serif editorial accent + mono metadata

Do not introduce additional font families without approval.

## Lore usage on simple site
Allowed:
- four-eye symbol
- subtle Tower Seven metadata
- technical marks
- low-level texture

Do not:
- explain lore on homepage
- turn sections into terminal screens
- use chapter labels unless tied to a real release
- use more than 2 lore motifs in one viewport

## Homepage content that must remain
- latest release
- live dates
- video
- merch
- mailing list
- gallery entry point
- booking/contact
- Tickets CTA when relevant

## Live states
Support:
- no public date
- exactly one date
- multiple dates

Single-date state must feel intentional and visually substantial.

## Mobile
Design mobile first for:
- live dates
- navigation
- hero
- CTAs
- image crops

At 375 px:
- no 4-column date tables
- no text overlap that harms readability
- no dependence on hover
- no oversized typography that clips critical words
