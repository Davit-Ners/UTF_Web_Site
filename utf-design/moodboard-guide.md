# Moodboard V2 Guide

The old moodboard should not simply be expanded.

Create a new, curated board whose purpose is to communicate a coherent design system.

Target: **20–30 strong references maximum**.

Quality over quantity.

---

## Category 1 — World / Atmosphere

Find references for:

- industrial megastructures
- brutalist architecture
- black monoliths
- cathedrals
- heat / furnace
- machinery
- surveillance
- dark urban environments

Question for every image:

> What exact feeling or visual principle do we want from this?

---

## Category 2 — Gerard / Creature language

Find references for:

- four-eye compositions
- humanoid silhouettes
- organic + mechanical hybrids
- cable / vein imagery
- unsettling but iconic creature design
- masks / faces / eyes

Avoid generic AI monsters.

Gerard needs recognisable rules.

---

## Category 3 — Editorial / Print

Find:

- metal posters
- experimental magazines
- album packaging
- tour posters
- brutalist editorial design
- fashion editorials
- photocopy / xerox layouts
- strong typographic composition

This category is especially important for the **simple website**.

---

## Category 4 — Photography

Find:

- concert photography
- flash photography
- motion blur
- high contrast
- black and white
- red / ember light
- smoke
- silhouettes
- crowd energy

---

## Category 5 — Web

Use only a few web references.

Do not save an entire website because it is "cool".

For each capture, label the reason:

```text
REF-01
Like:
- hero scale
- typography on edge
- no visible container

Do not copy:
- colour palette
- navigation
```

Possible reference categories:

- hero
- navigation
- release presentation
- tour dates
- video
- gallery
- transitions
- footer

---

## Category 6 — Technical / Archive

Find:

- engineering diagrams
- inspection documents
- redacted files
- thermal readouts
- old industrial manuals
- architectural plans
- timestamp systems
- warning labels
- scientific annotations

The goal is not to build a dashboard.

Use this as a detail layer.

---

# What NOT to collect

Avoid filling the board with:

- random dark fantasy
- unrelated anime landscapes
- generic cyberpunk
- "cool AI art"
- images with no relationship to the visual system
- too many unrelated illustration styles
- generic metal skulls
- neon gaming UI

---

# Reference annotation rule

Every useful image should answer at least one of:

- What do we like about the composition?
- What do we like about the type?
- What do we like about the texture?
- What do we like about the crop?
- What do we like about the colour?
- What do we like about the atmosphere?
- What do we like about the interaction?

If the answer is only:

> "It looks cool"

the reference is not useful enough yet.
