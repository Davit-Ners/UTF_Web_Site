# Homepage Content Inventory

## 1. Hero
Status: KEEP + REFINE

The current hero already has strong foundations:
- live photography
- oversized band logo
- clear genre/origin
- two useful CTAs

Do not redesign it from scratch.

Refine:
- navigation
- CTA styling
- text placement
- spacing
- image treatment
- integration with the new visual language

Remove:
- pill/capsule styling around genre text
- generic bright purple CTA treatment unless justified by the final palette

Goal:
make the existing hero feel authored rather than template-based.

Important:
